[INDEX_04] Engine Architecture
01
Logic

Core engine in optimised C++. Piece rotation, collision detection, and line-clearing, raw register operations, nothing wasted.

02
Display

I2C display. Let's you see your score full real time.

03
Controls

Basically up down left right.

04
Memory

PROGMEM optimisation to minimise SRAM usage. Efficient data structures for high memory demands.

05
Audio

8-bit PWM audio driver. Procedural chiptune generation: sound effects and the Korobeiniki melody, all synthesised in firmware.

06
Power

5V for classic Arduino bank. I'll update it to 9V later.

[INDEX_05] Specifications
Main Board ARDUINO UNO R3, 8 bit integer caps.
Clock Speed 16 MHz.
Flash Memory 32 KB (0.5 KB reserved for bootloader)
SRAM 2 KB, PROGMEM optimised for game state
Display 20 x 10 LED STRIP LIGHTS · WS2812B model
Input 4 push buttons + 1 analog joystick
Audio Piezo buzzer · PWM pin 3 · 8-bit driver
Power Nothing and · LDO regulated 5V rail
ARDUINO Dimensions IDK on this one really
Programming C++ · avr-gcc · Arduino IDE compatible
Communication Literally some wire and prayers
Enclosure Industrial · ergonomic handheld form factor

SHOWCASE · 00 · HERO BUILD
The Build

18×10 WS2812B LED strip lights mounted on a hand-cut board. Joystick and buttons wired to the board. Fits in two hands. Efficient. Runs tetris.

180 LEDS
~60ms FRAME TIME
